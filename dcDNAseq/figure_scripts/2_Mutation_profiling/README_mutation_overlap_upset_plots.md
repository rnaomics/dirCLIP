# Mutation Site and Region Overlap Plots

## Purpose

This script generates UpSet plots showing overlaps between significant mutation sites and mutation-enriched regions identified under different conditions.

## Input Files

Generated by:

```text
significant_mutations.R
```

Files used:

```text
Pos_mut_thresh_*.tsv
Pos_mut_thresh_*_region.tsv
```

## Methods

Overlaps are calculated using:

- GenomicRanges
- findOverlaps()
- findOverlaps()

Visualization is generated using:

- ggupset
- ComplexUpset
- patchwork
