# Mutation Rate Distribution Plots

## Purpose

This script generates mutation-rate distribution figures from mutation profiling results.

## Input Files

Generated by the mutation profiling workflow:

```text
Mutation_rate_cov_10_mut_0.tsv.gz
```

## Figures Generated

```text
Mut_Rate_nodel.pdf
Mut_Rate_del.pdf
Mut_Rate_del_nodel.pdf
```

## Description

The script:

1. Loads mutation-rate files.
2. Applies coverage thresholds.
3. Calculates boxplot statistics.
4. Generates mutation-rate distribution plots.
5. Compares mutation rates with and without deletion inclusion.

## Sample Groups

- SRSF3 dcDNA
- TotalRNA dcDNA no UV

## Output Directory

```text
Result/figure/1_Mutation_profiling/
```
