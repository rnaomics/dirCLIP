# Gene-wise Significant Mutation Site Analysis

## Purpose

This script summarizes significant mutation sites and mutation-enriched regions at the gene level.

For each gene, the workflow:

1. Identifies overlapping significant mutation sites.
2. Counts the number of mutation sites per gene.
3. Determines whether mutation sites overlap iCLIP peaks.
4. Calculates the fraction of mutation sites overlapping iCLIP peaks.
5. Generates gene-level summary tables.

---

## Input Files

### Significant Mutation Sites

```text
Pos_mut_thresh_0.03.tsv
```

### Significant Mutation Regions

```text
Pos_mut_thresh_0.03_region.tsv
```

Generated by:

```text
significant_mutations.R
```

### Gene Annotation

```text
genome/mm9/Annotation/gencode.vM1.annotation.gtf
```

### iCLIP Peaks

```text
SRSF3_merged.3nt_3nt.peaks.bed.gz
```

---

## Workflow

```text
Significant mutation sites
            ↓
Convert to GRanges
            ↓
Overlap with genes
            ↓
Overlap with iCLIP peaks
            ↓
Count sites per gene
            ↓
Calculate overlap fraction
            ↓
Generate gene-level summary tables
```

---

## Analysis Outputs

For each gene:

- Gene identifier
- Chromosome
- Gene coordinates
- Number of mutation sites
- Fraction of mutation sites overlapping iCLIP peaks

---

## Parameters

```r
Coverage_thresholds = c(50)
difference_thresholds = c(0.03)
Peak_callers = c("iCount")
```

---

## Notes

- Random chromosomes are excluded.
- Mutation sites are extended by ±5 nt before overlap analysis.
- Gene annotations are derived from Gencode.
- iCLIP overlap is calculated using GenomicRanges.
