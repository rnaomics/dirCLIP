# Motif Enrichment Analysis

## Purpose

This script identifies enriched sequence motifs around significant mutation sites and generates sequence-logo visualizations.

The workflow compares observed motif frequencies against two types of controls:

1. Shuffled sequences derived from the mutation-site sequences.
2. GC-matched random background sequences generated from matched genomic regions.

---

## Input Files

### Mutation-site FASTA sequences

```text

```

### Random background FASTA sequences

## Workflow

```text
Mutation-site FASTA sequences
            ↓
K-mer extraction
            ↓
Motif counting
            ↓
Background generation
        /         Shuffling      GC-matched random regions
        \         /
           ↓
      Z-score calculation
           ↓
   Fisher's exact test
           ↓
 Significant motifs
           ↓
 Sequence logo generation
```

---

## Statistical Analysis

For each motif:

- Motif counts are calculated from the mutation-site sequences.
- Background motif frequencies are estimated using shuffled or random-control sequences.
- Z-scores are calculated from the observed and background motif counts.
- Fisher's exact test is used to assess enrichment.
- Motifs passing the specified Z-score and p-value thresholds are retained.
