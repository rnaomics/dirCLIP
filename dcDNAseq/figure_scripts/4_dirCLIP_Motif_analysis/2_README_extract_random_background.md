# Motif Analysis Random Background Generation

## Purpose

This script generates GC-matched random control regions for motif analysis.

The generated background sequences are matched to significant mutation sites with respect to:

- Genomic region
  - 5'UTR
  - CDS
  - 3'UTR
  - exon
  - intron
- GC content

These random sequences are used as controls during motif analyses.

## Workflow

```text
Significant mutation sites
            ↓
Region annotation
            ↓
Assign transcript features
(5'UTR/CDS/3'UTR/exon/intron)
            ↓
Calculate GC content
            ↓
Generate random candidates
            ↓
GC matching
            ↓
Random control regions
            ↓
BED files
FASTA files
```

## Quality Control

The script includes the function:

```r
make_region_vs_difference_box_plot()
```

This function visualizes the GC-content difference between the real mutation sites and the matched random regions:

```text
GC(real regions) - GC(random regions)
```

The resulting plot can be used to assess the performance of the GC-matching procedure across different genomic feature classes.

---

## Genomic Features Used

Random background regions are generated from the same genomic feature class as the corresponding mutation site. The following genomic features are considered:

- 5'UTR
- CDS
- 3'UTR
- Exon
- Intron

Intergenic regions are excluded from randomization.

---

## Notes

- Chromosomes containing the string `random` are excluded.
- Strand information is assigned using overlaps with annotated genes.
- Random background regions are generated independently for each iteration.
- Multiple randomized background datasets are produced to improve robustness of downstream motif analyses.
- The generated FASTA files can be used directly as background sequence sets for motif discovery and motif enrichment workflows.
