# 🧬 Significant Mutation Site Identification Pipeline

This R pipeline identifies significantly mutated sites by comparing mutation rates between a target condition and a control condition.

The workflow:

1. Load mutation-rate files from multiple replicates.
2. Apply a coverage threshold.
3. Calculate mean mutation rates and SEM for each condition.
4. Calculate mutation-rate differences.
5. Perform one-sided t-tests.
6. Adjust p-values using Benjamini-Hochberg FDR.
7. Filter significant mutation sites.
8. Export TSV and WIG files.
9. Group nearby mutation sites into regions.

# Running the Pipeline

## Include Deletions (--incdel)

```bash
Rscript significant_mutations.R \
    --target_paths \
../Result/5_Mutation_profiling/3_Genome_Mapping/SRSF3_dcDNA/rep1_1pct/,\
../Result/5_Mutation_profiling/3_Genome_Mapping/SRSF3_dcDNA/rep2_1pct/,\
../Result/5_Mutation_profiling/3_Genome_Mapping/SRSF3_dcDNA/rep3_1pct/ \
    --control_paths \
../Result/5_Mutation_profiling/3_Genome_Mapping/TotalRNA_dcDNA_no_UV/rep1_0.2pct/,\
../Result/5_Mutation_profiling/3_Genome_Mapping/TotalRNA_dcDNA_no_UV/rep2_0.2pct/,\
../Result/5_Mutation_profiling/3_Genome_Mapping/TotalRNA_dcDNA_no_UV/rep3_0.2pct/ \
    --target_name SRSF3_dcDNA \
    --control_name TotalRNA_dcDNA_no_UV \
    --mutation_file Mutation_rate_cov_10_mut_0.tsv.gz \
    --coverage_threshold 50,100,200 \
    --diff_threshold 0.03,0.04,0.05 \
    --min_read_quality 8 \
    --min_base_quality 8 \
    --result_dir ../Result/5_Mutation_profiling/3_Genome_Mapping/SRSF3_dcDNA/ref_TotalRNA_dcDNA_no_UV/ \
    --incdel \
    --wiggle
```

# Parameters

| Parameter | Description |
|-----------|-------------|
| --target_paths | Target sample replicate paths |
| --control_paths | Control sample replicate paths |
| --target_name | Target sample name |
| --control_name | Control sample name |
| --mutation_file | Mutation-rate input file |
| --coverage_threshold | Coverage threshold(s), comma-separated |
| --diff_threshold | Mutation difference threshold(s), comma-separated |
| --group_threshold | Distance threshold for grouping sites into regions |
| --min_read_quality | Read quality used during profiling |
| --min_base_quality | Base quality used during profiling |
| --incdel | Include deletions in mutation rates |
| --wiggle | Export WIG tracks |

# Statistical Analysis

For every genomic position:

- Mean mutation rate is calculated across replicates.
- Standard error of the mean (SEM) is calculated.
- Mutation-rate difference is calculated:

```text
diff_mean = mean(Target) - mean(Control)
```

- One-sided t-test is performed.
- Benjamini-Hochberg correction is applied.
- Significant sites are filtered using:

```text
FDR < 0.05
AND
Mutation difference >= threshold
```

---

# Region Grouping

Significant sites are merged into regions when neighboring sites occur within:

```text
group_threshold
```

bases of one another.

Example:

```text
100
102
104
150
152
```

with:

```text
group_threshold = 5
```

becomes:

```text
chr1 100 104
chr1 150 152
```
